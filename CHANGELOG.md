# Changelog

Todas as alterações relevantes do CadernoFrete serão registradas neste arquivo.

## [0.1.0] - Não publicado

### Adicionado

- Estrutura inicial do aplicativo de controle de fretes, despesas, imprevistos e anotações.
- Calculadora de expressões e visualização detalhada dos dados do cálculo.
- Caderno com variáveis, destaque por sinal, zoom limitado e navegação responsiva.
- Persistência local no navegador.
- Logo oficial, favicon e manifesto do aplicativo.
- Documentação de contribuição, templates do GitHub e workflow de validação.

### Observações

- Esta é uma versão pré-release preparada localmente.
- Nenhuma release ou tag foi publicada.
