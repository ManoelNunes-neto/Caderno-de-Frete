# Caderno-de-Frete

Um caderno para ajudar motoristas com seus fretes.

Aplicativo React + TypeScript + Vite, com foco em Android, tablets e desktop.

## Executar

```bash
npm install
npm run dev
```

## Recursos

- Tela inicial com busca, fretes em andamento e concluídos.
- Criar, editar, excluir, salvar e finalizar fretes.
- Armazenamento local no navegador via `localStorage`.
- Cálculo de frete, despesas e imprevistos positivos ou negativos.
- Caderno manuscrito com variáveis destacadas.
- Zoom responsivo do papel com controles entre 75% e 120%.
- Botão Dados com o detalhamento de cada item do cálculo.
- Campos de dinheiro com expressões como `500 + 600` e `500 % 10`.

## Observações

O app é web e os dados ficam armazenados no navegador. Limpar os dados do navegador pode apagar as anotações.
